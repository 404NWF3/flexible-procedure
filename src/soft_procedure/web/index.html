产量与置信区间

仅计窗口内离开最终工位的成品。主指标为各次实验均值；95% t 区间描述重复实验均值的不确定性，1 次重复不计算区间。

周期与排队等待

周期从外部到达到成品完成，含待投料时间，仅统计已完成件；排队等待从进入工位缓冲到派工，不含换模。没有样本时显示 —。

利用率与平均队长

加工利用率 = 加工时长 / 总可用机床时间；换模、维修、阻塞、空闲单独记录。平均队长 = 队长曲线面积 / 观察时长。

配对与回放

各方案共享到达清单和按工件、工序绑定的加工样本。回放仅展示每方案第 1 次重复；保留的机床故障流按机床名称固定。
