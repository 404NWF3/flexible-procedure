# 案例22统一模型契约

本文件是 Arena 主模型与 SimPy 辅助模型的共同参数口径。原始 Arena 文件不在此文件中修改。

## 运行与到达

| 项目 | 统一口径 |
| --- | --- |
| 时间单位 | 分钟 |
| 观察窗 | `[0, 2400)`，空系统开始，无预热 |
| 批间隔 | `EXPO(10)` 分钟 |
| 批量 | `DU(5, 20)`，整数均匀 |
| 产品抽样 | 批次拆成单件后，每件独立抽样 |
| 产品比例 | P1/P2/P3/P4 = 30%/25%/25%/20% |

## 路线与资源

| 产品 | 路线 |
| --- | --- |
| P1 | M1(5) -> M2(8) -> M3(6) -> M4(4) -> M5(3) |
| P2 | M1(4) -> M3(7) -> M4(5) -> M5(6) |
| P3 | M2(6) -> M3(5) -> M5(8) |
| P4 | M1(3) -> M4(9) -> M5(4) |

- 机床数量：M1/M2/M3/M4/M5 = 2/1/2/1/2。
- 每个工位缓冲容量：50 件。
- 外部待投料和上游转入共用准入队列；外生到达持续发生。
- 加工完成后若下游缓冲已满，工件占用上游机床并进入阻塞状态。

## 换模与故障

- 同一台机床的当前产品类型与下一件不同，增加 15 分钟换模；相同类型不换模；首次加工免换模。
- 每台机床独立故障，MTBF=`EXPO(6000)` 分钟，MTTR=`EXPO(240)` 分钟。
- 故障中断加工或换模，维修后继续剩余工作；不设置共享维修工资源。
- FIFO 为基准；同类优先只改变已入缓冲工件的选择顺序，仍逐件加工。

## 评价口径

- 总产量与 P1-P4 分产品产量只统计完成全部路线的单件。
- 产出价值：`V = 200Q1 + 180Q2 + 250Q3 + 300Q4`。
- 运行小时：所有机床的加工时间和换模时间之和 / 60。
- 运行费：100 元/实际运行小时；当前模型按实际加工与换模时间计费。该费率是否已含折旧尚待任务书/教师确认。
- 新增机床购置价：500,000 元/台，作为资本投资单独记录，不在一个 2400 分钟周期内一次性扣除。
- 简化经营贡献：产出价值 - 运行费，不等同于净利润；在确认 100 元/小时不含折旧后，才另列设备折旧分摊后的期间收益。
- 折旧工作假设：直线法、10 年、残值暂按 0。若 2400 分钟代表一个生产周，则按 52 周/年折旧约 961.54 元/新增专用机床·模型周；按 50 个生产周/年则为 1,000 元。每年生产周数和模型周期与实际周的映射仍待确认。
- 每次实验必须检查：累计到达 = 完工 + 线内在制品 + 线外待投料。

成本拆分、折旧、回收期和待确认口径见 [`case22_economic_accounting.md`](case22_economic_accounting.md)。
