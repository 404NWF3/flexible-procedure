# Arena 修复登记

## 2026-10-17 安装后核验记录

已确认 Arena 16.20.02（Student/Training & Evaluation 模式）可启动。原始模型未覆盖；修复工作副本保存在用户本机的 `case22_arena_vv_20261017` 工作目录中。

只读检查原始 `Model1.db` 和 `.doe` 工作副本后，确认以下问题：

1. 原始数据库的 10 次重复均为 `StartTime=240`、`EndTime=2400`、`StatsCleared=1`、`IsWarmingUp=0`。因此当前结果统计窗口是 240–2400 分钟，不是统一契约要求的 0–2400 分钟。
2. M1–M5 的换模表达式均为 `(LastM#==ProdType)*15`。按照任务书，正确规则应为产品类型不同时增加 15 分钟，即 `(LastM#<>ProdType)*15`；首次加工仍需通过初始化值或条件保证免换模。
3. 故障模块原始 COM 读数为 `FailType=Time`、`FailCt=6000`、`FailUp=100`、上下时间单位均为 `Hours`、维修时间为 `EXPO(4)`。其中时间型故障的有效上机时间字段需要以 Arena 对话框实际映射为准，不能把 `FailCt` 误当作 MTBF。参数修复副本已将时间型故障的有效数值统一设为 6000、上/下时间单位设为 `Minutes`，维修时间设为 `EXPO(240)`。
4. 当前数据库输出主要是通用实体、资源和队列统计，尚未形成 P1–P4 分产品产量、阻塞时间和数量守恒所需的完整输出记录；旧数据库不能作为修复后 V&V 结果。

上述结论来自只读检查和 Arena COM 接口回读；未对 `.doe` 二进制文件进行盲目字节修改。已生成参数修复副本 `Model1_param_repaired.doe`，保存在上述本机工作目录中。

该副本尚未完成拆批模块和分产品输出，也尚未作为最终 V&V 模型运行。

## 2026-10-17 参数修复与拆批候选版本

通过 Arena COM 接口在副本上完成了以下修改，并保存为 `Model1_split_candidate.doe`，位于上述本机工作目录中。

- 运行长度 2400 分钟、重复次数 10、预热期 0、统计单位 Minutes；
- Create 的批量用 Arena 可编译的等概率离散分布替代任务书记号 `DU(5,20)`：
  `DISC(0.0625,5,0.125,6,...,0.9375,19,1,20)`；
- 新增 `Separate Batch`，类型 `Split`，数量 `BatchSize`，两条输出均接入后续流程；
- 新增 `Set Unit Batch Size`，拆批后将 `BatchSize` 设为 1；
- 原 `Assign` 的第 3 个重复赋值原本会再次生成 `5+AINT(UNIF(0,15.99))`，已改为 `BatchSize=1`；
- M1–M5 换模表达式改为 `(LastM#>0)*(LastM#<>ProdType)*15`，实现首次免换模、异类换模 15 分钟；
- 故障参数改为时间型、上机时间 6000 分钟、维修时间 `EXPO(240)` 分钟。

## 2026-10-17 Student V&V 新发现：完成出口逻辑反向

在 S02-P1 单产品确定性副本中，SIMAN 文本显示当前 Decide 分支为：

`If,Step==6,35$`，其中 `35$` 是 `Dispose 1`；而 `Else,32$` 指向 `Record OutPut`。

因此实体已经完成 P1 的五道工序并产生 26 分钟加工总时间，但完成实体被送入 Dispose 1，未进入产量和产值记录。该问题解释了 `Entity 1.NumberOut` 与 `Counter 1` 不一致，以及 S02 单产品实验中路线时间通过但产量/产值计数为 0 的现象。

修复目标为：

- `Step==6` 进入 `Record OutPut`；
- 路由条件未命中时进入 `Dispose 1` 作为异常出口；
- 修复后重新编译并运行 S01-S08；
- 在修复前不使用 Arena 产量或经济结果。

本次发现的独立证据文件为 `outputs/case22_arena_student_vv_20261017/Arena_Student_VV_S02_P1_fixed.mod`，其中保存了待验证的分支修正文本；原始 DOE 和原始 SIMAN 文件未覆盖。

| 顺序 | 修复项 | Arena 操作 | 验收条件 |
| --- | --- | --- | --- |
| 1 | 拆批 | Create 后增加 Separate，将批次拆成 BatchSize 个单件实体；单件独立抽取产品类型 | P1-P4 单件路线正确；产出按件统计 |
| 2 | 统计窗口 | Run Setup 中取消 240 分钟统计清零/预热，使用 0-2400 分钟 | 每次重复的统计起止为 0 和 2400 |
